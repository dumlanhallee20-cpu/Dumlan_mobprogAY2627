Laboratory Lab Activity 1: discussion 

In this activity, I learned how to build and enhance a social media newsfeed interface on Flutter using custom widgets and 
responsive design tools. At first, I ran into a few hurdles with rendering local image assets, structuring clean layouts, and
managing my Git branches properly when pushing updates to GitHub. I realized that for assets and custom components to work 
seamlessly, the file paths in the code must match the exact asset declarations in pubspec.yaml and repository branches must be 
synced carefully. To fix these issues, I used flutter_screenutil for responsive sizing, updated NewsFeedCard to support dynamic 
media, user avatars, and widget-based interaction buttons, and ran terminal commands like flutter pub get and git push to 
update my repository. Once everything was configured, the newsfeed screen displayed posts, images, and action bars cleanly on 
the emulator. This activity gave me a much better grasp of modular UI development in Flutter and showed me the importance of 
organizing assets and version control workflows properly.
